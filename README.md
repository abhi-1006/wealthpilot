# WealthPilot — SME Loan Underwriting & Credit Research Assistant

Capstone project for the Applied AI Professional Certification Program (IIT Hyderabad).
Domain: FinTech / Digital Lending. See [`ARCHITECTURE.md`](ARCHITECTURE.md) for the full
system design, evaluation results, and known limitations.

## Setup

1. Install dependencies:
   ```bash
   pip3 install litellm pydantic python-dotenv groq sentence-transformers rank-bm25 numpy \
       pypdf langgraph langgraph-checkpoint-sqlite supermemory langchain langchain-mcp-adapters \
       fastmcp mcp langfuse tenacity pandas fastapi uvicorn requests
   ```
2. Create `.env` in the project root with:
   ```
   GROQ_API_KEY=your_groq_key
   SUPERMEMORY_API_KEY=your_supermemory_key
   ```
   (Langfuse keys are optional for M7/M8 — both run correctly without them, tracing just won't
   reach a dashboard.)
3. The synthetic project data (policy corpus, intake records, mock API tables, golden eval set)
   is generated by `capstone-data-toolkit/` — see that folder's own README. It's already
   generated and committed under `capstone-data-toolkit/data/wealthpilot/`.

## Running each milestone

Each milestone is its own self-contained, runnable file:

```bash
python3 m1.py   # Intake: parse loan applications into validated Pydantic objects
python3 m2.py   # Tool-calling risk-analysis agent (DSCR, interest, bureau, bank-statement)
python3 m3.py   # Persistent memory (Supermemory) + tested summarization
python3 m4.py   # Production RAG over the policy corpus + 20-item eval
python3 m5.py   # LangGraph workflow with a real human interrupt + durable checkpointing
python3 m6.py   # Multi-agent underwriting committee + MCP server integration
python3 m7.py   # Observability (Langfuse) + reliability hardening (retry/fallback/breaker)
python3 m8.py   # Full eval + guardrails + FastAPI deployment package
```

`m2.py` through `m8.py` import from earlier milestones' files (e.g. `m2.py` imports the schema
classes from `m1.py`), so run from the project root.
